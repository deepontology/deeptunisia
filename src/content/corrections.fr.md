{#lede}

Chaque commit ayant touché le jeu de données, du plus récent au plus ancien. Cette page est générée depuis le contrôle de version plutôt que rédigée : personne ne décide quels changements sont assez flatteurs pour apparaître. Une affirmation erronée puis corrigée laisse ici une trace permanente et datée.

{#foot}

Le nombre de lignes est une indication d'ampleur, pas d'importance : un changement d'une seule ligne qui corrige une date compte plus que cent lignes de nouvelles citations. Lisez le commit pour savoir ce qui s'est réellement passé.

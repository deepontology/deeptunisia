# Inter-annotator study — instrument README

**Ready to run, not run.** This directory is the complete study instrument. No raters have been No raters have been recruited or paid; the dry run on 10 records proves the harness end-to-end.

## Files

| File | Purpose |
|---|---|
| `protocol.md` | Study protocol (research question, design, sampling, blinding, measures, procedure, timeline) |
| `rubric-v2.md` | Grading rubric as raters see it (confidence A–D, basis, decision tree, 5 worked examples) |
| `participant-protections.md` | Research ethics: pseudonymous participation, withdrawal, no publication of individual judgments, risk briefing, data handling |
| `sample-300.json` | Full 300-record sample with project grades (recomputable snapshot, **not** for raters) |
| `sample-300-blinded.json` | 300 prompts raters see (grades stripped, `study_id` S001…S300) |
| `sample-300-key.json` | Answer key: `study_id` → project grade (coordinator only) |
| `rater-template.csv` | Template raters fill (also per-rater shuffled views in `raters/`) |
| `raters/rater-{a,b,c}.csv` | Per-rater shuffled CSVs (generated by `study-blinding.ts --build`) |
| `kappa-report.json` / `.md` | Fleiss κ / Krippendorff α report (generated by `study-kappa.ts`) |
| `model-arm/` | Model-graded arm outputs (two prompt regimes) |
| `dry-run/` | 10-record dry run artifacts (see below) |

## Quick start (dry run)

```bash
# 1. Build graph (if needed)
npm run data

# 2. Sample 10 records (dry run) — deterministic, oversampled tail
npx tsx scripts/study-sampler.ts --n 10 --out research/study/dry-run --seed 20260902

# 3. Verify blinding (fails if any grade leaks to raters)
npx tsx scripts/study-blinding.ts --verify --sample research/study/dry-run/sample-10-blinded.json --key research/study/dry-run/sample-10-key.json

# 4. Build per-rater shuffled views
npx tsx scripts/study-blinding.ts --build --sample research/study/dry-run/sample-10-blinded.json --key research/study/dry-run/sample-10-key.json --out research/study/dry-run/raters

# 5. Grade (or use committed example grades in dry-run/raters/rater-{a,b,c}.csv)

# 6. Compute agreement
npx tsx scripts/study-kappa.ts --raters research/study/dry-run/raters/rater-a.csv,research/study/dry-run/raters/rater-b.csv,research/study/dry-run/raters/rater-c.csv --sample research/study/dry-run/sample-10-blinded.json --out research/study/dry-run/kappa-report.json

# 7. Model arm (synthetic if no API key; real LLM if OPENAI_API_KEY / ANTHROPIC_API_KEY set)
npx tsx scripts/study-model-arm.ts --sample research/study/dry-run/sample-10-blinded.json --out research/study/dry-run/model-arm --prompt rubric-only
npx tsx scripts/study-model-arm.ts --sample research/study/dry-run/sample-10-blinded.json --out research/study/dry-run/model-arm --prompt rubric+examples

# 8. Model-vs-model agreement
npx tsx scripts/study-kappa.ts --raters research/study/dry-run/model-arm/regime-a.csv,research/study/dry-run/model-arm/regime-b.csv --out research/study/dry-run/model-arm/kappa-model.json
```

## Full study (300 records)

```bash
npx tsx scripts/study-sampler.ts --n 300 --out research/study --seed <commitSha or fixed>
npx tsx scripts/study-blinding.ts --verify --sample research/study/sample-300-blinded.json --key research/study/sample-300-key.json
npx tsx scripts/study-blinding.ts --build --sample research/study/sample-300-blinded.json --key research/study/sample-300-key.json --out research/study/raters
# distribute raters/rater-{a,b,c}.csv to raters (not the key)
# collect grades, then:
npx tsx scripts/study-kappa.ts --raters research/study/raters/rater-a.csv,research/study/raters/rater-b.csv,research/study/raters/rater-c.csv --sample research/study/sample-300-blinded.json --out research/study/kappa-report.json
npx tsx scripts/study-model-arm.ts --sample research/study/sample-300-blinded.json --out research/study/model-arm --prompt both
```

## Scripts

- `scripts/study-sampler.ts` — stratified sampler (risk buckets, kind stratification, deterministic PRNG)
- `scripts/study-blinding.ts` — blinding harness (verify / build per-rater views)
- `scripts/study-kappa.ts` — Fleiss κ / Krippendorff α with bootstrap CIs and per-kind breakdown
- `scripts/study-model-arm.ts` — model-arm runner (two prompt regimes, simulator fallback)

Each script has `--help` via its header comment and `npx tsx scripts/study-*.ts --help` style (see file header).

## Acceptance

Acceptance: *a dry run on 10 records by the author produces the complete artifact set end-to-end.* That set lives in `research/study/dry-run/` and is force-added to the repository so a reviewer can inspect it without running anything.
